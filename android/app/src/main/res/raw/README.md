# Alarm Sounds

Place alarm sound files here with these names:
- `alarm_somnia.mp3` - Default gentle wake sound
- `alarm_progressive.mp3` - Gradually increasing intensity
- `alarm_gentle.mp3` - Soft pulsing tone
- `alarm_chimes.mp3` - Wind chime melody
- `alarm_nature.mp3` - Nature/bird sounds

These files will be played by AlarmService when the alarm triggers.

If a sound file is missing, the system default alarm sound will be used.

## Recommended Specifications
- Format: MP3 or WAV
- Duration: 30-60 seconds (will loop)
- Sample Rate: 44100 Hz
- Bit Depth: 16-bit
- Loudness: Normalized to -14 LUFS
